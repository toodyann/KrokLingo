# Банк буклетів «Крок 1. Стоматологія» (англійською)

Скрипти, якими зібрано `apps/api/bank/*.json`. Кожен файл — окремий збірник; API копіює їх у базу під час старту.

## Джерела

- **Буклети 2007–2018** — PDF ЦТ на сайті ОНМедУ (`https://onmedu.edu.ua/wp-content/uploads/2023/01/Buklet-Krok-1-Stomatology-<рік>E.pdf`). У цих буклетах правильна відповідь завжди перша (A); у застосунку варіанти перемішуються.
- **2018 (англ. субтест), 2020, англійська проф. 2022–2024** — сторінки medical-club.net з тестами H5P, де позначено правильні відповіді. Тексти для читання беруться зі сторінки перед кожним блоком.

Не використано:
- буклети 2020–2025 з ОНМедУ — це скани без ключа відповідей;
- krokly.org — його robots.txt забороняє автоматичний збір;
- testkrok.org.ua — закритий для автоматичного перегляду.

## Як перезібрати

Команди виконуються з теки `apps/api`.

Робоча тека `<src>` з підтеками `pdf/`, `txt/`, `html/`.

1. Завантажити PDF у `<src>/pdf/onmedu-<рік>.pdf`, а сторінки medical-club — у `<src>/html/` (назви файлів див. у `MC` в `build.cjs`).
2. Витягнути текст двома способами:
   ```bash
   pdftotext <src>/pdf/onmedu-2012.pdf <src>/txt/onmedu-2012.raw.txt
   node scripts/booklets/columns.mjs <src>/pdf/onmedu-2012.pdf <src>/txt/onmedu-2012.cols.txt
   ```
   - `raw` (pdftotext) точніший, коли нумерація проходить усі 200 питань.
   - `cols` (mupdf, з урахуванням колонок) рятує сторінки, де pdftotext змішує колонки (2008, 2011).
3. Зібрати:
   ```bash
   node scripts/booklets/build.cjs <src> bank
   ```

## Що робить збірка

- Розбирає питання й варіанти. Відкидає пошкоджені, наприклад групи крові, де PDF втратив символи A/B.
- Прибирає дублікати між роками: однакове питання з тією самою відповіддю лишається в найновішому буклеті.
- Призначає дисципліну (`classify.cjs`). Для кожного питання рахуються бали за:
  - ключовими словами в тексті;
  - тим, про що саме питають в останньому реченні («What receptors initiate this reflex?», «What hypoxia type…»);
  - типом варіантів відповіді: нерви, ферменти, препарати, мікроорганізми, клітини чи хвороби.

  Початок буклета впорядкований за дисциплінами, тому його розбито на послідовні блоки. Порядок «мікробіологія ↔ патологія» в різні роки різний, тож перевіряються обидва. Якщо власні ознаки питання явно сильніші за позицію в блоці, перемагають вони. Решта буклета класифікується по одному питанню.

  Точність перевірено вручну на 190 випадкових питаннях: 90% (раніше 80%). Підтеми (анатомія голови, ембріологія, імунологія, патофізіологія) визначаються вже в застосунку (`src/data/topics.ts`).
