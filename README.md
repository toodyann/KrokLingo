# KrokLingo

Інтерактивний тренажер для підготовки до іспиту **«Крок 1. Стоматологія»** англійською мовою: симуляція іспиту з таймером, вільне тренування за темами та словник невідомих слів із миттєвим перекладом.

Працює повністю у браузері. Бекенду немає, усі дані зберігаються в `localStorage`.

**Демо:** https://toodyann.github.io/KrokLingo/

## Можливості

- **Симуляція іспиту:** 50 завдань, зворотний таймер на 100 хвилин, автоматичне завершення, коли час вийде. Кількість завдань, час і поріг змінюються в налаштуваннях.
- **Вільне тренування:** без обмеження часу; можна вибрати збірники й теми, задати кількість питань або повторити лише ті, де були помилки.
- **Клікабельний текст:** кожне англійське слово в питаннях, текстах для читання та варіантах відповідей можна натиснути. На комп'ютері переклад з'являється в поповері біля слова, на телефоні — в аркуші знизу (закривається свайпом). Слова, які вже є у словнику, підсвічуються маркером у всіх текстах.
- **Словник невідомих слів:** кожне натиснуте слово автоматично зберігається. Слова можна редагувати (уточнити медичне значення, додати примітку), позначати вивченими, видаляти, повторювати картками та експортувати в `.txt` чи `.docx`.
- **Статистика наживо:** під час тесту видно таймер, номер питання, кількість правильних і неправильних відповідей та поточний відсоток.
- **Шкала прогресу:** графік результатів усіх спроб із лінією тренду та порогом, успішність за темами, динаміка.
- **Підсумковий звіт:** бали, витрачений час, відсоток, вердикт «склав / не склав» (поріг за замовчуванням 40%), детальний розбір кожного питання та список нових слів цієї сесії.
- **Імпорт збірників** у форматі JSON і **резервна копія** всіх даних.

## Банк питань

Вбудовано 117 оригінальних питань у форматі Кроку 1. Кожне має 5 варіантів відповіді та пояснення англійською.

| Збірник | Теми |
| --- | --- |
| Базові медичні дисципліни (88) | анатомія, гістологія та ембріологія, фізіологія, біохімія, мікробіологія, фармакологія, патологія |
| Професійна англійська (29) | термінологія та граматика, читання (4 тексти) |

Питання написані спеціально для цього застосунку. Вони не скопійовані з комерційних платформ (Krokly, TestKrok тощо), бо ті бази захищені авторським правом. Щоб тренуватися на реальних буклетах Центру тестування, імпортуйте їх як JSON (див. нижче).

### Вбудований словник

Для всіх слів банку питань є офлайн-переклад: близько 1400 базових форм. Лематизатор зводить словоформи до словникових (`teeth` → `tooth`, `caused` → `cause`, `bacteria` → `bacterium`). Слова з імпортованих збірників, яких немає у вбудованому словнику, перекладаються онлайн через MyMemory; це можна вимкнути в налаштуваннях.

## Формат імпорту (JSON)

```json
{
  "collection": "Буклет 2024",
  "questions": [
    {
      "topic": "anatomy",
      "text": "Which nerve provides motor innervation to the muscles of mastication?",
      "options": ["Mandibular nerve", "Maxillary nerve", "Facial nerve", "Hypoglossal nerve", "Vagus nerve"],
      "correct": "A",
      "explanation": "Optional explanation."
    },
    {
      "topic": "reading",
      "passageTitle": "Dental caries",
      "passage": "Reading text shown above the question…",
      "text": "According to the text, …",
      "options": ["…", "…", "…", "…", "…"],
      "correct": 2
    }
  ]
}
```

- `correct` задається як літера (`"A"`–`"E"`), номер-рядок (`"1"`–`"5"`) або індекс від 0 (`0`–`4`).
- `topic` може бути одним із вбудованих (`anatomy`, `histology`, `physiology`, `biochemistry`, `microbiology`, `pharmacology`, `pathology`, `terminology`, `reading`) або будь-якою власною назвою.
- Питання з однаковим текстом `passage` згрупуються під одним текстом для читання.

Шаблон можна завантажити в розділі **Налаштування → Імпорт питань**.

## Дизайн

Інтерфейс побудовано за Apple Human Interface Guidelines і принципами «fluid interfaces»:

- **Шари.** Таб-бар на телефоні й верхня панель на широкому екрані. Напівпрозорий матеріал є лише на панелях, аркушах і поповерах, а контент лежить на суцільних картках.
- **Типографіка.** Текстові стилі Apple (Body 17/22 тощо); питання й тексти для читання набрані шрифтом із засічками.
- **Кольори.** Кожен колір має одне значення: синій — взаємодія, зелений і червоний — правильно й неправильно, жовтий маркер — слово у словнику. Контраст тексту не нижчий за 4.5:1 у світлій і темній темі.
- **Рух і жести.** Анімації побудовані на пружинах, які можна перервати. Аркуші тягнуться пальцем і закриваються з урахуванням швидкості жесту.
- **Відгук.** Реакція на натискання миттєва, цілі натискання не менші за 44 px.
- **Доступність.** Враховано `prefers-reduced-motion`, `prefers-reduced-transparency` і `prefers-contrast`.
- **Скасування.** Оборотні дії можна відкотити кнопкою «Скасувати», без діалогів підтвердження.

## Стек

React 19, TypeScript, Vite, Oxlint. Без UI-бібліотек: графіки зроблені на SVG, пружинна анімація власна, а `.docx` збирається власним ZIP-записувачем.

## Розробка

Потрібен Node.js 22.12+ (версія закріплена в `.nvmrc`).

```bash
nvm use
npm install
npm run dev
```

| Команда | Що робить |
| --- | --- |
| `npm run dev` | Дев-сервер з гарячим перезавантаженням |
| `npm run build` | Перевірка типів і продакшн-збірка в `dist/` |
| `npm run preview` | Локальний перегляд продакшн-збірки |
| `npm run lint` / `lint:fix` | Перевірка коду Oxlint |
| `npm run typecheck` | Лише перевірка типів |

## Структура

```
src/
├── data/            банк питань (questions/), теми, вбудований словник (glossary.ts)
├── lib/             лематизатор, переклад, сесії тесту, експорт .txt/.docx, імпорт, сховище
├── store/           глобальний стан і збереження в localStorage
├── components/      клікабельний текст, підказка з перекладом, питання, графіки
└── pages/           головна, іспит, тренування, тест, результати, прогрес, словник, картки, налаштування
```

## Деплой

Кожен пуш у `main` збирає застосунок і публікує його на GitHub Pages (`.github/workflows/deploy.yml`).

Перед першим деплоєм потрібно один раз увімкнути Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
